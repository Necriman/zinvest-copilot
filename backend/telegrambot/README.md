# Zinvest Telegram bot — оформление

Все 11 баннеров подключены к соответствующим экранам и появляются при каждом
открытии раздела. Под ними — короткие HTML-подписи и нативные кнопки Telegram.
Фото/голосовые записи по-прежнему требуют подтверждения; текстовые записи
сохраняются сразу, с кнопкой отмены. Привязка аккаунта, уроки, лига и напоминания
сохранили свои сценарии. Переводы: русский, английский и узбекский.

## Стикеры в диалогах

Все 10 стикеров медведя распределены по сценариям в `reactions.py`:
приветствие — wave, привязка — clap, деньги — coin, сохранение/ответ — happy,
проверка чека/вопрос — think, голосовые/настройки — phone, обучение — book,
лига/итоги — cheer, завершение обучения — celebrate, отмена/пауза — sleep.
Стикеры отправляются после полезного сообщения, без отдельного звукового
уведомления. Повторные отправки используют `file_id`, сохранённый в
`TelegramAsset`; ошибка стикера не отменяет основное действие.
`TELEGRAM_STICKERS=false` отключает стикеры.

## Ответы ИИ и скорость

Бот использует отдельные параметры Gemini, не меняя модель ИИ на сайте:

```dotenv
TELEGRAM_AI_MODEL=gemini-2.5-flash
TELEGRAM_AI_TIMEOUT_SECONDS=25
```

Если модель не задана, используется `GEMINI_MODEL_FLASH`. Время ожидания
ограничено для сетевого запроса; короткие ответы ограничены 900 выходными
токенами, распознавание — 1400. У моделей 2.5 Flash/Flash Lite отключён
дополнительный thinking; другим моделям этот параметр не передаётся.
Настройки и ключ сайта не изменяются, учёт токенов ответа остаётся в ADVISOR.

Ошибки Gemini больше не оставляют вопрос без ответа: бот показывает сообщение
о недоступности. Текст ИИ экранируется перед отправкой, поэтому `<`, `>` и `&`
не ломают Telegram HTML. Месячные суммы вычисляются одним запросом агрегирования
вместо загрузки всех записей в Python.

Проверить настройки и выполнить один тест без пользовательских данных и
отправки сообщений в Telegram:

```powershell
.\.venv-windows\Scripts\python.exe manage.py telegram_ai_check --probe
```

Команда различает отсутствие ключа/SDK, ошибки доступа, недоступную модель,
исчерпание квоты и сетевые ошибки. Ключ не выводится. После изменения кода или
переменных окружения перезапустите работающий процесс бота/backend.

## Премиум-эмодзи

В `premium_emoji.json` подключены 15 значков: 6 из набора, присланного владельцем
21 сентября 2026 года, и 9 из
[IconsBlueEmoji](https://t.me/addemoji/IconsBlueEmoji), проверенных через
`getStickerSet`. Значки используются в тексте и кнопках.
Остальные значки остаются обычными эмодзи.

| Значок из присланных скриншотов | ID | Где используется |
| --- | --- | --- |
| Зелёный знак денег | `5197434882321567830` | Раздел «Деньги», меню, доход |
| Белый кошелёк | `5424976816530014958` | Итог за месяц |
| Цветной график | `5431577498364158238` | Кнопка открытия финансов в приложении |
| Приветствующая ладонь | `5195448447062251797` | Приветствие и главное меню |
| Рукопожатие | `5332728658543022473` | Успешная привязка аккаунта |
| Синий щит Telegram | `5350291836378307462` | Предложение подключить аккаунт |

Обычный emoji внутри HTML-тега соответствует присланному владельцем, даже
когда рисунок custom emoji отличается (например, `✈️` → щит Telegram).

По [Telegram Bot API](https://core.telegram.org/bots/api#formatting-options),
для custom emoji в личных чатах владельцу бота нужен Telegram Premium либо
подходящий дополнительный username с Fragment. Получателям Premium не нужен.
При явном отказе Telegram с ошибкой premium/custom emoji запрос повторяется
один раз с обычными эмодзи. Сетевые таймауты автоматически не повторяются.

- `TELEGRAM_PREMIUM_EMOJI=false` — отключить custom emoji.
- `TELEGRAM_ILLUSTRATED_CARDS=true` — показывать все баннеры (включено по умолчанию).
  Значение `false` включает текстовый режим. Исходные изображения сохранены.

### Как включить право на премиум-эмодзи

1. Войдите в Telegram под аккаунтом, которому принадлежит бот.
   Проверить: откройте [@BotFather](https://t.me/BotFather), отправьте `/mybots`
   и найдите своего бота.
2. На этом аккаунте откройте **Настройки → Telegram Premium** и проверьте,
   что подписка активна. Premium на другом аккаунте не даёт боту это право.
3. Отдельного разрешения на custom emoji в BotFather включать не нужно.
   Premium нужен владельцу, а не самому боту или каждому пользователю.
4. Если в окружении сервера ранее отключали оформление, установите:

   ```dotenv
   TELEGRAM_PREMIUM_EMOJI=true
   TELEGRAM_ILLUSTRATED_CARDS=true
   ```

5. Перезапустите процесс бота или backend с webhook. Откройте личный чат
   с ботом, отправьте `/start`, затем `/settings`: у настроек появится баннер
   и премиум-значки. Старые сообщения автоматически не перерисовываются.

Эта инструкция относится к личным чатам, в которых работает этот бот.
Для отправки custom emoji в каналы действуют другие ограничения Telegram.

Для другого набора из `t.me/addemoji/<имя>`:

```powershell
.\.venv-windows\Scripts\python.exe manage.py telegram_emoji <имя>
.\.venv-windows\Scripts\python.exe manage.py telegram_emoji <имя> --write
```

Команда сначала запрашивает реальный набор у Telegram; `--write` сохраняет
только совпадающие значки. Для отдельных эмодзи доступен прежний `/emoji`.

## Применение

Перезапустите процесс бота (polling) или backend, принимающий webhook.
Чтобы обновить описание профиля и меню команд в Telegram:

```powershell
.\.venv-windows\Scripts\python.exe manage.py telegram_setup
```

Настройки транспорта, токен и рабочая база не менялись. В ходе разработки
сообщения реальным пользователям не отправлялись.

## Проверка

```powershell
.\.venv-windows\Scripts\python.exe manage.py test telegrambot --noinput
```

`preview.html` — локальный макет на основе текстов и кнопок бота с примерными
данными. В браузере показаны обычные эмодзи; настоящие custom emoji и их
анимация отображаются клиентом Telegram. Цвета и размеры элементов зависят
от темы и версии Telegram.
